NEON SWARM — a top-down arena survival shooter built from scratch in plain canvas JavaScript. WASD to move, mouse to aim, hold click to fire, Space to dash. Survive wave after wave of chasers, shooters and splitters, chain kills into a ×5 combo, and grab drops that heal, speed up fire, spread the shot or raise a shield. One hull, no second chances.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
